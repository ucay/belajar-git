# Workspace

Folder ini digunakan untuk latihan mandiri tiap peserta.

Standar format folder:

```text
workspace/
  ucay/
  member-1/
  member-2/
  participant-3/
```

Setiap peserta bisa membuat file latihan di folder masing-masing.

Contoh:

```text
workspace/ucay/
  01-clone-notes.md
  02-commit-practice.md
```

Catatan:
- nama folder sebaiknya konsisten dan mudah dipahami
- sebagai fasilitator, Anda bisa menambahkan username baru kapan saja
