# Modul 06 - Rebase dan Cherry Pick

Catatan latihan Git.

## Rebase
Rebase menyusun ulang commit berdasarkan titik awal yang baru.

## Cherry-pick
Cherry-pick menyalin perubahan dari commit tertentu ke branch aktif.

## Latihan Cherry-pick
Commit ini dibuat di branch sementara untuk latihan cherry-pick.

## Latihan Stash
Pekerjaan ini belum selesai dan disimpan sementara.
