# Catatan Final Project

## Kebiasaan Kerja
1. Periksa branch aktif dengan git branch.
2. Periksa perubahan dengan git status.
3. Tinjau perubahan dengan git diff.
4. Stage hanya file yang dibutuhkan.
5. Buat commit dengan pesan yang jelas.
6. Periksa riwayat setelah latihan.
7. Pastikan working tree bersih setelah selesai.

## Kerja Tim
Sebelum merge, periksa perubahan, pahami konflik, dan pastikan hasil akhirnya sesuai kebutuhan bersama.
