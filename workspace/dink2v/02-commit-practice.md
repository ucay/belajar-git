# Latihan Commit dan Staging

Commit yang rapi membuat riwayat perubahan mudah dibaca dan dipahami. Pesan commit sebaiknya menjelaskan perubahan yang dilakukan.

Memisahkan perubahan ke dalam commit kecil membantu kita meninjau kode dan mencari sumber masalah dengan lebih mudah. Setiap commit sebaiknya berfokus pada satu tujuan.

Commit yang jelas juga memudahkan kerja sama tim karena anggota lain dapat memahami alasan perubahan tanpa harus menebak-nebak. Sebelum commit, periksa perubahan menggunakan git diff dan git status.

Revisi: Saya memeriksa perubahan sebelum commit agar hanya perubahan yang tepat yang disimpan.
