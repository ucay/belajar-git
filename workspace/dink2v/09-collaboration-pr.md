# Modul 09 - Workflow Kolaborasi dan Pull Request

## Tujuan
Berlatih workflow kolaborasi menggunakan branch fitur, commit, push, dan Pull Request GitHub.

## Alur Kerja
1. Sinkronkan branch dasar sebelum mulai bekerja.
2. Buat branch fitur dengan nama yang jelas.
3. Ubah file yang diperlukan saja.
4. Periksa perubahan menggunakan git diff.
5. Jalankan git diff --check.
6. Commit perubahan dengan pesan yang menjelaskan tujuannya.
7. Push branch fitur ke GitHub.
8. Buat Pull Request untuk meminta review.
9. Periksa perubahan dan diskusikan perbaikan sebelum merge.

## Aturan Aman
- Jangan menggunakan git add .
- Jangan melakukan force push.
- Jangan mengubah atau menghapus riwayat commit yang sudah ada.
- Jangan merge sebelum review selesai.
- Branch main tetap tidak berubah selama latihan ini.

## Status Latihan
- Branch fitur dibuat dari dink2v.
- Perubahan diperiksa sebelum commit.
- Pull Request akan digunakan untuk latihan review.
