# Final Project - Ringkasan Belajar Git

## Yang Saya Pelajari
Saya mempelajari clone, staging, commit, remote, fetch, pull, branch, merge, conflict resolution, rebase, cherry-pick, tag, revert, reset, dan stash.

## Modul Paling Sulit
Modul yang cukup menantang adalah merge conflict dan reset karena perlu memahami perubahan pada file serta riwayat commit.

## Cara Resolve Conflict yang Membantu
Saya membandingkan perubahan dari kedua branch, menentukan isi akhir yang benar, memeriksa file hasil resolusi, lalu melakukan commit merge.
