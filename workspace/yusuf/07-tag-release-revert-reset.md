Melakukan git reset : digunakan untuk membatalkan 1 commit terakhir, tanpa menghapus atau menghilangkan perubahan kode yang sudah dibuat

Melakukan git revert HEAD : fungsinya sama namun membuat commit baru

git stash : digunakan untuk menyimpan perubahan yang belum selesai agar bisa dilanjutkan nanti

git stash pop : mengembalikan perubahan yang disimpan di stash
