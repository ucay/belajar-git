# Shared

Folder ini digunakan untuk latihan kolaboratif dan merge conflict.

Contoh file:
- `shared/team-notes.md`
- `shared/learning-plan.md`

Aturan:
- file di sini ditulis bersama-sama oleh tim
- setiap peserta bisa mengedit file yang sama untuk simulasi conflict
- setelah conflict di-resolve, commit dan push hasilnya
